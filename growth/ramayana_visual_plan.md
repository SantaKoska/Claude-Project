# A garage to ₹1,000 crore (Ramayana): visual plan

Voice: `audio/ramayana.mp3` (Adam, Malayalam), 40.2 s raw, 21 phrases aligned; synced to **38.2 s** (tempo 1.0, 1.3 s hold before the twist).

## Owner's direction (25 Nov 2026)
"Use Avengers Doomsday type of video": the same dark premium cinema hall (`lib/cinema3d.js`), the screen as the only strong light, real photos and big numbers on the screen, a ticket stack on the armrest, flare and light leak on the twist.

## What changed from Doomsday
- `lib/cinema3d.js`: the printed ticket text is now an option (`new CinemaWorld(canvas, screens, { ticket: { title, line } })`); here it reads RAMAYANA · PART 1 · 20 DAYS · HOUSEFULL.
- Screen cards carry only the big word or number (₹1,000 CR, 1995, PRIME FOCUS, OSCAR, RAMAYANA, ₹4,000 CR+, ₹973 CR); the details live in the pills, so screen text never collides with the pills or captions.
